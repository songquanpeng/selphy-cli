首个 Mac 桌面客户端 **SELPHY Studio**，使用 Go + Wails，直接复用已验证的 selphy-cli 内核。

- 支持 JPEG、PNG、WebP、HEIC，提供成品、裁切线、完整图三种预览。
- 可调整相纸、留白、满版、裁切、旋转、画质，自动沿用现有实物校准。
- 支持发现打印机、保存默认设备、查询状态与纸墨、连接诊断和按相纸校准。
- 打印前显示系统确认，固定照片和预览设置，支持进度与取消，失败不自动重试。
- 提供无标线 JPEG 导出及 Dock 安装脚本。

### 下载

- `SELPHY-Studio-0.2.0-macos-arm64.zip`：适用于 Apple Silicon Mac，macOS 12 或更新版本；解压后将 SELPHY Studio 拖入“应用程序”。日常使用无需 Go 或 CLI。
- `selphy-0.2.0-darwin-arm64`：可选的独立命令行工具。
- `SHA256SUMS-0.2.0.txt`：以上文件的 SHA-256 校验值。

桌面应用已使用 Developer ID 签名。本次为私有仓库试用版，**未经过 Apple 公证**；下载到另一台 Mac 时，系统可能要求确认来源。当前本机安装不受影响。

### 验证

17 项界面测试、11 项 Go 桌面适配层测试、全仓库 `go vet` / race 测试及 GitHub CI 均通过。已检查原生导入、预览、导出、打印确认取消和重启恢复，并验证 ZIP 解压后的签名与版本号。

本轮打印机处于关闭状态，没有重新进行实际出纸测试；CP1500 沿用 CLI 已验证的打印逻辑。QX10 / QX20 的真机验证边界详见 README。
