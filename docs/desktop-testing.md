# SELPHY Studio 桌面验收

本地验收日期：2026-11-02。目标是 Mac Apple Silicon 本机试用；安装包使用现有 Developer ID 签名。本轮不运行实际出纸测试，打印机处于关闭状态。

## 自动化测试

`go vet ./...`、`go test -race ./...` 覆盖原 CLI 和新增适配层。桌面适配层 11 个测试覆盖：

- 通过真实 CLI 生成完整 JPEG、裁切线 PNG 和成品预览。
- 导出 JPEG 格式及拒绝覆盖已有文件。
- 打印使用选择时的照片副本、预览时的校准与参数，原图与外部配置变更不影响该任务。
- 旧预览、不兼容相纸和无效参数不能提交打印。
- 重复打印、并发操作及上传后网络失败不触发第二次提交。
- 配置持久化，校准按设备 / 机型 / 相纸隔离。
- 取消传播、关闭后拒绝新操作、私有临时目录清理。
- 损坏文件不替换有效照片及预览。
- macOS `sips` 的真实 HEIC 导入和转换（非 macOS 跳过）。
- 打印确认信息来自固定的照片、设备和相纸。

`cd desktop && npm test` 用模拟 Go 桥接运行 17 项 Playwright 界面测试，覆盖启动、照片导入、三种预览、设置变化、相纸兼容性、校准保存、导出、打印确认取消、成功与失败后的预览失效、无自动重试、打印进度、取消、离线错误、搜索设备、状态查询、诊断、快捷键及最小窗口布局。

浏览器测试验证界面行为；Go 测试验证真实 CLI 的离线调用。实际打印调用在测试中拦截，核对输入、唯一提交、取消与日志转发，不消耗纸墨。

## 原生 Mac 验收

使用安装到 `/Applications/SELPHY Studio.app` 的实际签名构建检查：

- 冷启动和重启，读取已有默认设备与实物校准。
- macOS 系统照片选择器导入本地测试 PNG，Go 内核生成并显示三种预览。
- 裁切线不进入打印数据，界面显示已保存的校准补偿。
- 系统打印确认与取消；取消后没有提交任务。
- 系统导出选择器和无标线 JPEG 导出。
- 打印机关机时查询失败可恢复；系统局域网权限已启用，离线预览仍可使用。
- Developer ID 签名通过 `codesign --verify --deep --strict`。
- 应用固定到 Dock；退出后保留图标，重新打开可正常启动。

CP1500 的真实出纸和裁边补偿沿用已验证 CLI 的结论。本次没有重新验证物理打印结果；QX10 / QX20 的硬件验证边界仍以项目 README 为准。CP 的“回到空闲”不等于肉眼确认成品，客户端明确提醒检查实物。

## 复现

```sh
make test
cd desktop && npm ci && cd ..
make desktop-test
make desktop-install
```

CI 分别检查 CLI/适配层、Playwright 界面和 macOS 桌面编译，不接触开发者证书、个人照片或实际打印机。
